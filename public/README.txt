A v3.7.7 Apple + Melon cube integration

1. Replace your current src/main.js with this package's src/main.js.
2. Copy both GLB files into the project's public/ folder.
3. Run: npm.cmd run dev

White targets load apple_cube.glb. Black targets load melon_cube.glb.
If your project uses a different entry file, copy the edited source into that file.
The code keeps a temporary box visible until both GLB assets load.
